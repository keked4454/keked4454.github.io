Codex

最简单的方法是使用 GitHub 网页端上传 + GitHub Pages，不需要敲命令。

1. 创建仓库

登录 GitHub，点击右上角 + → New repository。

仓库名有两种选择：

  • 推荐：你的GitHub用户名.github.io
  • 例如用户名是 keked123，仓库就叫 keked123.github.io
  • 最终网址：https://keked123.github.io/
  • 普通仓库名，例如 personal-website
  • 最终网址：https://你的用户名.github.io/personal-website/

设置：

  • Visibility 选择 Public
  • 可以不勾选 README
  • 点击 Create repository

如果使用 GitHub 免费账户，Pages 通常需要公开仓库。GitHub Pages 官方说明

2. 上传网页文件

在 Finder 中打开：

/Users/keked/Desktop/mis3011 wk1/site

进入 site 文件夹后，选择里面的全部内容：

  • index.html
  • styles.css
  • main.js
  • content.js
  • favicon.svg
  • README.md
  • assets 文件夹
  • vendor 文件夹

回到刚创建的 GitHub 仓库：

1. 点击 uploading an existing file，或者 Add file → Upload files。 2. 将上述文件和文件夹拖入上传区域。 3. 等待所有文件上传完成。 4. Commit message 填写：Add personal website 5. 点击 Commit changes。

关键点：仓库首页必须直接看到 index.html。不要上传成：

site/index.html

正确结构是：

index.html
styles.css
main.js
content.js
assets/
vendor/

GitHub 网页端单个文件上限为 25 MiB，你的网站最大文件约 1.07 MB，可以正常上传。GitHub 文件上传说明

3. 开启 GitHub Pages

上传完成后：

1. 进入仓库的 Settings。 2. 左侧选择 Pages。 3. 找到 Build and deployment。 4. Source 选择 Deploy from a branch。 5. Branch 选择 main。 6. 文件夹选择 / (root)。 7. 点击 Save。

这是 GitHub 官方推荐的无构建静态网站发布方式。Pages 发布来源设置

4. 获取网站地址

通常等待一到几分钟，然后重新进入：

Settings → Pages

页面顶部会出现：

Your site is live at …

点击 Visit site 即可。GitHub 官方说明首次发布最多可能需要约 10 分钟。

最后交给老师两个地址：

  • 网页地址：https://你的用户名.github.io/
  • 代码仓库地址：https://github.com/你的用户名/你的仓库名

以后修改网站，只需要重新上传对应文件并提交，GitHub Pages 会自动更新。
